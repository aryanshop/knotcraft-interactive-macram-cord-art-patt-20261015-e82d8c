# KnotCraft: Macramé & Cord Art Studio

KnotCraft is an interactive design tool and pattern calculator built for fiber artists, knot tyers, and macramé creators. Plan wall hangings and plant hangers visually before cutting expensive cords.

## Features

- **Visual Knot Library**: Drag-and-drop structural knots (Square Knots, Half Hitches, Spiral Knots, and Gathering Knots) onto an adjustable canvas grid.
- **Custom Cord Styling**: Customize cord color and thickness per node or globally.
- **Automated Calculations**: Instantly estimates total cord length needed, hanging width, and generates a breakdown summary.
- **Project Blueprint Export**: Export your design as a JSON file or print a project summary sheet directly from your browser.

## Local Run Instructions

1. Download or clone all files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No server setup or external dependencies required—runs 100% locally and statically.

## Technology Stack

- Vanilla HTML5
- Modern CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
